# AT 風格選單縮圖

AT 自動剪輯的風格選單（v2 起十七種，代號 A～Q）每張卡片上的示意圖。選單透過 jsDelivr 讀這裡的圖：

```
https://cdn.jsdelivr.net/gh/TW-Rick/at-style-thumbs@<tag>/<檔名>.jpg
```

- 畫面裡的人是 **AI 生成的數字人**（Google Flow / Nano Banana 生成），不是真人。
- 台詞是示範用的同一段 15 秒口播，每種風格各套一次。
- 換圖時請打新的 tag（v2、v3…），選單改指新 tag；舊 tag 的網址不會變。
- v1：十二種（A～L）。v2：加介面風五類（M～Q），H 換成角落小框看得到肩膀的新版。
